# 《被看见之后》叙事改版设计

日期：2026-09-26  
状态：用户已确认方向，按确认后的要求实施  
范围：整合现有页面叙事和可视化，接入可追溯的公开报道；统计序列仍待团队核验

## 目标与约束

把当前偏章节展陈的阅读体验改成一条可跟随的调查：非遗技艺被集中看见之后，关注是否到达现场，是否引发实际参与，是否留下跨时间的持续实践证据。读者应在每个阶段知道调查问题、当前证据状态、证据能支持的判断和仍然未知的部分。

主题仍是“爆火现象背后是否真的传承”，不是非遗文化介绍或宣传。视觉和技术效果必须承载报道问题。全国名录、安徽资料、鱼灯与徽墨个案仍作为不同尺度的证据，不把它们拼成未经证明的因果链。

不编造数据。地图点阵仍为动效占位；只接入已核对原始出处的公开报道、人物和单点指标，并逐条呈现来源与口径。不制作模拟统计图，也不把报道片段误认作传播时间序列。保留来源弹窗、模型与示意图说明、无障碍/减少动态支持，以及鱼灯与徽墨制作体验。

## 研究参照

- [Sigma Awards 评审标准](https://www.sigmaawards.org/rules/)把数据采集与分析、故事讲述、互动视觉和公共价值共同作为评价方向。对本项目的启发是：动效需要协助读者判断证据，而不是独立占据注意力。
- [The Guardian：How did 1,000 prisoners die?](https://www.theguardian.com/news/datablog/2012/may/23/italian-prisoners-deaths)将地图中的数字与地点和具体故事联系起来。对本项目的启发是：空间可视化需要说明每个记录所代表的对象，并给出从总览进入个案的路径。
- [The Guardian：Think like a data journalist](https://www.theguardian.com/news/datablog/2012/nov/14/think-like-data-journalist)强调调查、研究事实、分析和讲述是一体的。对本项目的启发是：先提出可回答的问题，再选图表，不先摆视觉模块再补说明。

## 建议的阅读结构

### 开篇：热度是怎么被看见的

用一句调查问题开场，简短交代为何选取“被看见之后”作为观察窗口。鱼灯模型作为个案入口保留，但将其标注为原创示意，控制首屏占比，使标题、问题和研究对象成为主信息。墨迹交互退为轻量背景，不与首屏问题竞争。

### 第一段：先界定“爆火”

把现有“屏幕上的热度”改为叙事第一站。建立一条明确的传播证据带：平台、指标、时间范围、统计口径和来源；有可比时间序列后才绘制趋势图。不同平台各自计量，不把播放、搜索、讨论量合成一个热度分数。暂无数据时，使用文字型“待核验”状态条和需要补齐的字段，不显示空坐标轴或装饰性图表。

### 第二段：从屏幕到现场

把现有地图/名录可视化移到这里，并从“看见非遗全貌”改为“这股关注落在哪些地方与活动”。全国/安徽名录只作为背景基线，必须与活动到访、体验报名等传播后参与证据分层显示；地图标注数据单位、年份、来源和空缺。地图到鱼灯的点云聚合仅作为段落转场，配以文字明确其是视觉隐喻，不暗示地理数据变成鱼灯。

### 第三段：追踪同一个案例

将现有 `CaseTrail` 移入主要调查线，作为全页的叙事主轴。鱼灯、徽墨选择器仍保留，但每个案例统一沿着“事件/传播节点 → 首次参与 → 活动结束后”的时间线组织报道材料。每一节点预留日期、对象、事件记录、可比较指标、来源和证据等级。只有同一案例、同类指标、可核验的跨期记录才能画变化连线；无法追踪处显示缺口，不用理论阶段伪装成已发生时间线。

### 第四段：参与到持续实践之间

将鱼灯与徽墨的制作小游戏嵌入各自案例的“第一次动手”节点，视觉尺寸从主叙事降为可选体验。游戏结束后用一条简洁提示连接调查问题：一次体验能显示哪些制作环节，无法证明学习时长、掌握程度或持续实践。原有独立的“人物图谱”不再以网络关系作为主可视化；无经过核验的人物关系数据时，改为个案时间线里的来源明确的人物记录位置。

### 结尾：证据允许我们说到哪一步

保留现有证据判断互动，但改为贯穿全文的结论检查：分别展示“已支持”“仍未知”“不能据此推断”。只有资料填入并经过来源/口径核验后，才从“暂不判断”更新结论。结尾回扣开篇问题，并列出最关键的缺失证据，而不是以泛化宣传语收尾。

## 页面和组件层面的处理

- 以“热度 → 现场参与 → 持续实践”替换现有六个并列章节的主导航；章节锚点减少到开篇、三段调查和结论。原六个主题作为段落内的小标题或资料入口，不丢弃其有效内容。
- 全宽滚动叙事由正文主导；减少重复标题区、并列卡片墙和多处“等待资料”的同质提示。每个数据位紧邻其对应的问题和解释。
- 保留来源弹窗和来源编号，正文图表就近显示口径摘要；完整方法说明在统一的方法/来源入口查看。
- 保留地图、鱼灯/徽墨模型和工艺游戏，但限定用途：地图呈现核验后的空间背景，模型承担案例识别/转场，游戏解释工艺步骤。视觉转场始终标注示意属性。
- 缩减纯装饰性关系图、重复证据卡及与调查节点脱节的图形。将动效重点集中在一处“地图—点云—鱼灯”转场和案例时间线的阶段推进。
- 响应式阅读、键盘可用、减少动态模式和 WebGL 不可用时的静态替代需要保留。

## 成功标准

1. 未读过项目背景的读者可用章节导航说出调查的三步：界定热度、观察参与、追踪持续实践。
2. 页面中不存在将空数据包装成真实趋势、地图分布或人物关系的可视化。
3. 每个可视化都能回答一个明确问题，且有口径、来源和局限说明入口。
4. 鱼灯/徽墨体验和三维效果支持案例理解，不再形成彼此孤立的“展品区”。
5. 键盘与手机阅读、减少动态、WebGL 降级仍可完成主要叙事。

## 主要涉及位置

- `src/App.tsx`：页面总叙事顺序、章节导航和主视觉位置。
- `src/content/story.ts`：调查阶段标题、导语、证据问题与边界说明。
- `src/content/data.ts`：只保留真实记录集合为空的状态及字段要求，不加入示例值。
- `src/components/Sections.tsx`、`src/components/Investigation.tsx`：章节与调查节点重排、合并。
- `src/effects/chinaMap.ts`、`src/effects/RelationshipGraph.tsx` 及相关样式：地图转场语义、弱化无证据关系图、统一长文叙事节奏。
- `src/styles/sections.css`、`responsive.css`、`effects.css`：正文宽度、阶段标记、图表占位与移动端布局。

## 尚待确认的编辑取舍

本方案不新增未经采集的报道内容，不删除鱼灯/徽墨体验，也不以示意互动替代数据。若团队后续交付了可核验数据，实际图表类型按字段和可比性决定；本设计不预设一律使用折线图、地图或漏斗。

实施补充：用户随后强调大学生数字编辑大赛的技术呈现，并授权直接完成、做好回档。最终在结论段增加交互证据连接图：公开报道记录作为节点，只有来源确认同一对象跨期出现时才画实线；否则画虚线并解释缺口。可追溯的新华社、人民日报报道以个案材料接入，不作为全量统计。
