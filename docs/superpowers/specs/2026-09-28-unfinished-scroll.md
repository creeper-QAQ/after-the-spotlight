# 未完的长卷 · 数字编辑实验版

用户授权直接制作大胆、有视觉奇观且有传统文化质感的尝试版。保留已清洗数据、来源入口及既有点云、证据墙、工坊；将作品定位从数据新闻模板升级为互动文化叙事。占位只用于视觉意象和文案，不生成假统计。

## 本轮设计

1. **纸灯序幕**：墨绿黑背景、超大宋体、朱砂和旧金。Remotion Player播放原创鱼灯线描从骨架到灯光、再到光点的12秒序幕；三个镜头按钮及进度拖动让观众控制镜头。离屏暂停，减少动态时静止但能手动操作。
2. **百工印谱**：99枚可点击的印记，每枚对应一条现有安徽子项。排列可以切换为“散落的印记 / 十类手艺 / 认定批次”。用形态变化表达分类，同一条记录在所有排列中身份不变。点击揭示名称、编号、申报地区与保护单位。箭头键可遍历印记，读者可返回常规表格查阅。
3. **续线台**：在结尾用一根未接合的线提出问题。指针或键盘控制线头，完成三个可解释的动作：看见、动手、再回来。每一步只有体验反馈，不产生观众统计或传承分数。最终呈现“屏幕能接上一根线，现实需要一次次回来”，并邀请读者选择继续追踪的证据问题。
4. **编辑节奏**：黑色序幕—纸白正文—朱印互动—证据与制作—暗色续线收尾。折叠长资料线索及人物表，缩短默认阅读路径。保持与主题有关的互动，避免所有元素同时运动。

## 实施顺序

保留起始快照 → Remotion序幕与新首屏 → 99枚印谱 → 续线台 → 响应式及动效控制 → 真实浏览器交互、视觉、既有功能检查 → 私有Sites发布与快照。

## 验收证据

- 第一屏1440与390像素实拍检查：标题、艺术画面、入口互不遮挡，首屏有明确视觉主体。
- 序幕可播放/暂停、切三镜头、拖进度；离屏不持续播放；减少动态可直接使用。
- 印谱恰有99枚，分类数及批次总数与清洗数据一致；三种布局明显不同；点选和键盘查询展示同一原记录。
- 续线三步可用鼠标、触屏点击与键盘完成，重置可重新体验；结果不伪装成调查数据。
- 所有新增功能在手机可操作，320/390/1440宽度无横向溢出；来源可打开、关闭。
- 原有鱼灯/徽墨游戏、点云转换、证据墙的浏览器回归通过。
- 构建通过、控制台无未处理错误，最后截图与复核记录保存到artifacts。
- Sites仅发布经过筛选的静态产物，不包括原始调查文件和内部附件。
