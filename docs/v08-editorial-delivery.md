# 《被看见之后》V0.8 交付与核验

交付日期：2026年10月1日。公开来源核对日期保留为2026年9月30日。

## 这一版改变了什么

阅读主线改为：纸灯序幕 → 三条发现 → 传播记录 → 证据口径切换 → 三条实名人物路径 → 三维制作体验 → 四种证据状态 → 真实回访提纲 → 可选资料卷。

新增10个原始公开来源、15条带时间和范围的证据记录，以及潘敏、申易鑫、汪华武三条跨期人物路径。来源、出版日期、核对状态、解释与限制保存在 `src/content/public-evidence.json`；卷末可逐条展开查看。研究笔记见 `docs/research/fish-public-evidence-20260930.md`、`ink-public-evidence-20260930.md`。

播放次数、研学接待人次、工坊订单、实名制作和教学分别解释。选取的10份报道证据片段采用目的性选取；覆盖矩阵只判断选取片段能支持什么，不推断行业总体比例。体验者持续学习比例保持 `null / 未知`，不把缺失当作零，不拼接转化漏斗。

99枚印章、随机点位地图、名录、人物台账与旧资料案卷保留在默认收起的卷末。地图继续说明随机布局与非真实分布；待复核记录保留状态。

原公开网络头像改为原创文字身份，虚构评论标识在手机上常驻。原视频保留为第三方创作参考，加载不影响正文；减少动态时不自动播放。132个旧头像保存在 `docs/archive-assets/avatars`，已移出公开素材与成品 `dist`。

印章物理位置与React布局位置改为独立属性；切换门类、年份和散落布局后不再残留旧物理坐标。手机三维操作台在说明文字之前。游戏四阶段与真实工艺、制作时间、学艺时间明确区分。

结尾回到真人与可执行的回访提纲。AI只作为可选整理工具；服务端提供固定公开证据上下文。未配置服务或静态成品无接口时明确提示暂未开启，保留提纲，不显示可发送的空服务。关闭工具会终止状态查询与回信请求。

## 独立复核

独立只读评审发现并修复三项实质问题：主入口跳过发现页、夜间正向证据标签对比度不足、减少动态时视频仍自动播放。入口测试先观察到失败，再确认修复；夜间对比度和减少动态行为通过实际浏览器检查。二次复核确认修正；新增AI可用状态与15条证据索引未发现新的重要问题。评审对事实采用研究记录对照，原文核对由研究阶段完成。

## 成品与维护

本地成品预览：`http://127.0.0.1:4173/`。开发预览：`http://127.0.0.1:5173/`。

静态部署用 `dist`。开发服务的AI与音频代理由 `vite.config.ts` 提供；静态站点不会自动获得这些服务。若以后启用AI，需要单独部署 `/api/reply-status` 与 `/api/deepseek-reply`，密钥只留在服务端。当前静态正文和离线提纲已经完整。

主包约301KB gzip；Three模块约153KB gzip，地图特效约891KB gzip。图形模块拆包，地图在资料卷展开并进入视野后加载。Vite仍给出大模块提示；没有以关闭告警声称体积问题消失。

本轮编辑保留原有未提交工作，不重置、不合并或推送。起始备份为 `20260930T152806Z-before-editorial-rebuild-2882ce`，最终备份编号记录在执行台账。现有公开材料已经足以描述实名制作者的接续；体验者转成持续学习者仍需真实的同批回访，不能从公开播放与接待数字补算。
