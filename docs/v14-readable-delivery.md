# V1.4 清晰主线版

交付日期：2026-10-13。用户已批准鱼灯为主、徽墨作对照的书面设计及六项实施计划，并选择当前目录执行与最终独立复核。

## 改动

主线由历史、传播、学习、日常接续四章组成。新增7项事实，登记共24项、13项来源；原10组选片段编码和94条台账不变。地图与地图加载代码移除，人物时间线及方法移入默认折叠的证据中心；正文资料编号可打开对应来源。

阅读设置在顶栏，从第一屏即可使用，手机有“阅读”文字。减少动态停止背景影片、流体、印谱物理运动与回访工具逐字显示；同一工具尊重实际页面选择。主动制作、原文查阅与下载继续可用。

主线删去重复数字、空泛疑问与描述标签。完整来源和创作属性收在资料说明。开篇保留直接制作与证据中心入口，制作介绍不连续重复同一标题。

## 验证项目

主线检查覆盖320、390、768、1440像素的章节顺序、一次播放数字、无地图请求、人物及方法折叠、来源定位、唯一ID、顶栏44像素目标与焦点恢复。制作检查覆盖两门完整流程、键盘、触摸、进度、重置、来源及WebGL失败重试。

媒体检查包含播放、暂停恢复、定位循环、离屏暂停、失败静帧和系统减少动态；全程阻断站外请求。动效检查还覆盖运行中关闭、恢复及存储禁用。助手检查覆盖新事实、上下文、继续追问、停续、资料引用、下载、系统和页面减少动态，以及零API请求。

对应运行记录与截图位于artifacts/readable-story、artifacts/local-reply及测试声明的目录。静态生产与最终ZIP解压运行的结果写入交付验收.json；文件SHA-256逐项核对。
