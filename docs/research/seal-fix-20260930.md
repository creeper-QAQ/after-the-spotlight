## 根因与修改

Matter 每帧直接写入按钮 `style.left/top` 的像素值，覆盖 React 维护的百分比。模式切换后，部分印记的新旧 React 百分比相同，React 不会重写该属性，留下物理坐标。现在物理引擎仅写独立 `--physics-left/top/rotation`，专用 `layout-physics` CSS 消费这些变量；React 始终保留静态排列坐标。卸载物理模式时清除变量、事件、帧和引擎，印记仍使用同一个 `row.id` key。

手机的静态排列采用6列17行，850px舞台和36×42px印记，保留99条全部记录且不旋转越出舞台。选择态不放大覆盖相邻印记。物理模式继续支持触控拖拽，拖动后不触发选中。键盘 Enter 查看记录、方向键切换仍可用，添加可见焦点。减少动态模式预先结算并停止持续运行，手机跳转详情遵从减少动态设置。

`src/styles/seal-repair.css` 由 `SealAtlas.tsx` 自行导入，无需修改全局入口。
