# V1.4.1 追问与接续版

日期：2026-10-14。用户已在聊天中确认本轮短设计，并授权直接实施与桌面、手机、静态交付验证。

## 叙事变化

开篇提出“鱼灯火了，这门手艺会有人接着做吗”。来历与热闹之后，先问“屏幕外，真的有人来学吗”，用现场与课程记录给出第一个答案。随后追问“来过一次，就会留下来吗”，以一件作品的制作投入引入制作体验。再次沿潘敏与申易鑫的同名跨年记录寻找后来，展示从学艺到持续教学，最后解释青年就业、师带徒、劳动报酬和场地支持，积极结论落在具体实践上。

新增四组可视化：课程名额排布、同名人物跨年路径、青年从业占比切换、分级师带徒横条。保留原印谱、头像评论、静音影片、两门制作及本地回访工具。首次学习者与后续人物对应范围明确，没有将来访家庭写成已完成回访的同一批学徒。
