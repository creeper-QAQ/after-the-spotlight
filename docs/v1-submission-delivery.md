## 作品与阅读流程

作品从安徽鱼灯与徽墨出发，追问被看见之后，手艺怎样进入日常。开篇前置三项发现，沿公开报道追踪潘敏、申易鑫与汪华武的教学和制作；把播放、接待、实名实践分别核对，并补充歙县鱼灯相关行业的年轻从业者记录。

主线顺序：纸灯序幕 → 三条发现 → 热度记录 → 头像人声 → 百工印谱 → 地图点云聚成鱼灯 → 证据尺度与调查板 → 全94条指标的单位结构 → 三条人物路径 → 三维工坊 → 结论与回访提纲。印谱、地图与调查板均可直接在主线阅读，不需先展开附录。卷末收纳原文、证据登记及较深的名录与资料台账。

头像库当前含507张，桌面每批132张、手机每批66张；298句原创声音循环配用。默认浮出评论气泡已去掉，单独阅读区保留悬停预览、点击选择、翻页和键盘操作。评论不会自行轮播。界面标注“原创声音示意”，并说明头像、身份、声音均为叙事示意、非采集样本。换批及手机、桌面之间切换会保留当前选择。

鱼灯与徽墨的选择同步调查板、人物技艺标记与制作台，两门制作分别保留本次会话的进度。开篇也可直接进入制作和来源；人物章节提供三个直达入口，完整时间线继续在主线阅读。

## 原创背景灯影

头像段使用随包交付的原创三维灯影短片：960×540、10秒、静音WebM，来自本站原创鱼灯模型与原创庭院场景。它是工艺意象，不是现场实录或报道证据。

影片由原生video呈现，没有第三方播放器控制栏、广告或登录提示。保留独立暂停、恢复入口；离开这段或切换到后台时暂停。减少动态、视频加载失败时使用同源静帧，评论与文字继续可用。第三方参考影像保留为单独注明的外链，未下载或重新分发其视频。

成片使用浏览器原生MediaRecorder导出。真实帧数、有限时长与SHA-256以“docs/research/lantern-film.md”和生成验证记录为准；不将目标帧率当作实测帧率。验证覆盖连续播放与自然循环，不能只以抽帧成功证明成片可播放。

## 分析与资料边界

10份公开来源各对应一组相关证据片段。四项编码为：被关注2/10组、到访体验6/10组、实名实践9/10组、同批体验者追踪0/10组。项目允许重叠，分母是本次目的性选取的10组，不是人数、全网报道全集或随机样本。判定规则、逐条备注与来源在界面中可复核，尚未开展独立双人编码一致性检验。

新增全台账检查涵盖全部94条清洗采集指标：28种非空单位写法，另3条单位缺失；10个单位文字分组可逐行展开。30条用途笔记对应14个不同网页，仍保留待复核状态。这是采集台账的结构统计，包含待核实、计划或缺值记录，不将这些记录升级为已确认新闻事实，不把同类单位中的不同对象、平台、时间窗、币种或数量级相加。

17条正文事实与3条人物路径带时间、单位、对象、来源和解释边界。正文、报告精选与对应指标共用核对事实，17.1亿次、19万人次不会在不同展示中分别维护；原始采集台账保留原值。修改核对事实的测试验证重复展示同步、台账原值保持。

新华社记载歙县1400余人从事鱼灯相关行业，其中35岁以下占比超50%。范围是县域三项非遗鱼灯的相关行业，不是某村制灯师傅、首次入行者或新增学徒；不能据此推导短视频造成了多少新人入行。[新华社原文](https://www.news.cn/local/20251107/75ca609714dd4898a437a1fde157d554/c.html)

体验者持续学习比例仍未知。所选公开片段没有连接同一批体验者的首次体验与后续学习，0/10组不是留存率0%，也不能推断整个行业没人留下。回访提纲明确为尚未开展的工作，不虚构采访结果。

来源逐条保留复核日期。平台报告增加[光明网同报告转载](https://m.gmw.cn/toutiao/2025-02/18/content_37857670.htm)作为备用阅读入口，属于同一报告，不另增一份独立来源。包内保留记录与链接，不打包完整报道。

安徽名录、人物和线索仍保留原文待复核、关联待匹配等状态。地图点位是原创视觉意象，不代表真实坐标或传播轨迹；四阶段工坊简化工艺动作与时间，不代表完成学艺培训。

## 打开与使用

完整解压成品包，Windows电脑双击“打开作品.cmd”。系统自带PowerShell启动仅供本机访问的HTTP预览，浏览器自动打开实际地址，默认从4180端口起尝试空闲端口。以启动窗口显示的地址为准，保持窗口打开，无需Node、npm或额外安装。端口被占用时按“先读我.txt”改用4181。

正文、头像、印谱、地图、数据、工坊、灯影片段与静帧均在本地包内。原文及第三方参考影像的外链需要网络。回访问题卡可直接下载，包含读者的问题和三个阶段的追问、匿名编号、日期、行为及核对字段。下载不上传输入，收起后保留本页草稿，刷新后清空。静态版不查询AI服务，也不显示不可用按钮；已配置的开发服务可额外提供AI回信，密钥不随包公开。

site目录可供静态托管，完整保留结构，通过HTTP访问。直接双击index.html不能完整运行模块。源码维护使用Node.js 22.12+或24系列，运行npm ci、npm run dev；构建运行npm run build。

## 验收与维护

事实、全台账复算、来源覆盖筛选、正文主线与共享案例选择均有对应检查。布局覆盖320、390、768与1440像素；手机尺寸由浏览器模拟，不声称实体手机认证。三维工坊检查鱼灯与徽墨的完整制作、键盘操作、进度保持、重置、来源、WebGL失败与重试。
