# 制作体验（V0.5）

鱼灯与徽墨改为直接在作品画面上操作，材料、骨架、纸面、鳞纹、灯光和墨锭会随操作改变。每道工序明确写出本步动作与已完成的位置数；发光点可点击或按住划过，支持手机触摸和键盘聚焦后按 Enter。

- 鱼灯：连接 4 处骨架 → 覆 4 片纸面 → 选择颜色并绘 6 处鳞纹 → 点亮灯芯。
- 徽墨：收集 3 处烟料 → 沿碗边搅拌 4 处 → 落 3 槌 → 下压压杆 → 在烈日与阴凉处选择晾墨位置 → 描 3 处金纹。

游戏保留即时反馈、错误提示、工艺说明与完整的鱼灯/墨锭结果画面。压杆可直接拖动，也提供键盘可用的按钮。这里的动作次数只是教学示意，不对应真实配方、工时、品质或学习结果。每一步的事实依据见 `src/content/story.ts` 的 `craftLessons` 及页面“查看工序来源”入口。

实现为 `src/components/CraftStudio.tsx`；桌面、手机、拖杆、错误提示与两条完整路径由 `tests/games.mjs` 验证。V0.4 的卡片拖放版保存在 `.versions` 中。
