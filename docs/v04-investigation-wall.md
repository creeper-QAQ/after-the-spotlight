# V0.4 调查路线与证据墙

## 读者路线

开篇提出具体问题：一户住客制作鱼灯，一间工坊后来仍在接单，这两件事能否连成“传承”？正文先界定“热度”的口径，再区分全国名录与现场参与，然后沿鱼灯或徽墨的公开报道进入证据墙。制作体验放在“参与”之后，让读者亲手感受参与的深浅。结尾用逐项核对和具体判断回答开篇问题：目前有关注、现场体验和既有实践的记录，但没有同一批体验者的后续追踪，因此不能判断一次走红带来了传承。

## 实现与参考

- 证据墙：三张原创剪报卡、来源链接、随滚动揭示的调查红线；最后一段用断开的虚线标明缺少同一批人的追踪。桌面和手机均保持证据墙可见，让文字推动核对。方法参考 [Scrollama 的 sticky graphic 模式](https://github.com/russellsamora/scrollama) 与 [The Pudding 的滚动叙事设计说明](https://github.com/the-pudding/how-to-implement-scrollytelling)。本项目使用 React 与浏览器滚动位置自行实现，没有复制上述项目代码或视觉素材。
- 交互参考 [The Pudding《Women's Pockets are Inferior》](https://pudding.cool/2018/08/pockets/)：用连续追问和可视化让证据逐步出现，并明确告知读者存在滚动动画。本项目保留减少动态的设置。
- 制作体验：鱼灯 4 步、徽墨 6 步，每步只有“把一件材料放到一个目标”一个动作。支持指针拖入、手机点选以及键盘 Tab/Enter 操作。拖放触摸处理参考 [dnd-kit 对移动端 pointer 与 touch-action 的说明](https://github.com/clauderic/dnd-kit/issues/272)；组件为本项目原创，没有加入第三方拖放依赖。真实工序说明沿用现有有来源的 `craftLessons`，屏幕次数不代表真实工时。
- 既有中国地图与点云过渡继续作为“从全国背景到具体案例”的转场，但地图点阵仍是视觉示意，不得称为真实项目分布。地图章节的资料槽与来源说明仍可供后续接入数据。

## 需要继续补的证据

最关键的是同一批体验者的隔期学习、制作或教学记录，至少包括可同意公开的匿名 ID、首次参与日期和方式、后续核访日期、后续实践状态、核访方法和原始来源。另需可比较的平台热度序列与现场去重参与数；不同单位不能直接相除得到“转化率”。

## 下一轮可视化候选（数据到位后再接入）

1. **名录地图 / 现场地图双层切换**：同一个地理视角切换“哪些项目被认定”与“哪些地点有可核验体验活动”，不混用项目数、活动数和参与人数。[Mapbox Storytelling 模板](https://github.com/mapbox/storytelling)提供了章节与地图视角同步的参考。需要地理编码、地点精度和项目/活动的独立字段。
2. **参与深度剖面**：观看、到场、短时体验、连续学习以并排条带呈现；每条只展示自己的口径与时间段，不做未经证实的转化漏斗。点击一条可进入具体报道或访谈原文。需要每一层的去重人数和可比较的时间范围。
3. **结论的证据拨盘**：读者切换“仅看官方名录”“加入报道”“加入同人隔期追访”，结果卡随证据级别变化；灰色缺口保持可见。只有收集到可核验原始记录后，才能把最后一档做成实际判断，不能用模拟数字填充。
