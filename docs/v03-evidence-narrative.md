# V0.3 · 调查叙事与证据连接

## 这版的讲述顺序

网站以“界定热度 → 观察参与 → 追踪同一项技艺 → 核对结论”组织内容。每一段都先提出一个可调查的问题，再展示相关记录、统计空缺和解释边界。地图到鱼灯的点云动画承担从全国视野进入个案的转场；它不表示真实项目位置或数据转化。鱼灯与徽墨小游戏作为“第一次动手”的辅助体验，放在案例追踪之后。

结尾的交互证据连接图有两种阅读方式：“查看公开记录”展示三段报道；“核对同一批人”只在记录具备经来源确认的同一对象标识时连接实线。当前材料涉及不同主体，因此连接为虚线。该图表达了本次调查的关键缺口：有传播、体验与工坊实践的报道，仍缺同一批体验者后续学习的追踪。

## 参考的数据新闻表达

- [Sigma Awards 评审标准](https://www.sigmaawards.org/rules/)：调查和数据分析需要与视觉叙事共同成立。本版让互动回答“这条结论需要哪种证据”。
- [Reuters，《Buildings wrapped in solid gasoline》](https://www.reuters.com/graphics/BUILDING-FIRES/byprqyryzve/)：以具体案例切入，再逐层解释材料、机制与更大范围的问题。本版用鱼灯个案承接地图视角，并将制作体验放在“参与”节点。
- [The Guardian，意大利狱中死亡数据报道](https://www.theguardian.com/news/datablog/2012/may/23/italian-prisoners-deaths)：让地图记录回到具体地点和人物。本版将名录背景与个案报道分开，避免地图点位承担未经证实的推断。
- [The Pudding，《Can an AI make a data-driven, visual story?》](https://pudding.cool/2024/07/ai/)：允许读者切换过程与结果，显露报道方法。本版的证据连接图提供“公开记录/同一批人”两个核对标准。

以上只借鉴叙事和交互方法，没有复制现成项目的代码、图片或素材。

## 下一轮数据到位后需要做什么

1. 给全国与安徽名录逐条填项目、类别、地区、批次及来源。不同认定级别与地区子项分开统计。
2. 为“爆火”补同平台、同指标、明确时间范围的传播序列；单个账号粉丝数不能代替传播趋势。
3. 为活动参与补到访/体验人数与去重口径，并尽可能取得同一批人后续学习、制作或教学记录。
4. 只有确认同一对象跨期资料时才为 `CaseEventRecord.subjectId` 填相同标识。该标识驱动证据图中的实线，不能凭姓名相似或同项目自行推断。
5. 把资料出处、统计口径及缺失说明与每个新增数字同时发布。
