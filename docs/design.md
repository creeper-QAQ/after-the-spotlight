# 初版设计依据 · 2026-09-22

本轮根据用户明确指示直接实现初版，用于视觉效果与网站风格校对。沿用已讨论的电影感滚动叙事与双案例交互方向，核心始终是数据新闻。此版本是视觉原型，未声称研究数据已采齐。

- 暖纸白、朱红、墨黑；中文宋体大标题与清晰的正文排版；宽幅图表空间。
- 首屏原创程序鱼灯模型；允许旋转，工艺章节提供结构拆解及徽墨切换。
- 全国名录、传播指标、人物、案例对照均留有独立数据位置；不存在的数值不填零、不编造。点阵只作为显式标注的布局示意。
- 章节导航、阅读进度、来源弹窗、阅读设置、移动端导航都必须能操作。
- 内容与数据在content目录；视觉变量在tokens.css；模型、章节和图表独立组件。
- 本地快照含文件哈希，恢复前自动备份，恢复到新目录而不覆盖现场；项目Git里程碑提供额外历史。
- 桌面与手机可读；减少动态、WebGL失败时不影响正文。

验收：生产构建通过；真实浏览器检查首屏和整页；交互与移动端验证；模拟WebGL不可用；实际备份恢复并比较文件哈希。
