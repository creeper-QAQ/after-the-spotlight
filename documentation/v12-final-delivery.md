# V1.2 交付收尾

日期：2026-10-01。基于V1.1提交定稿做最后一轮阅读与交付优化。本轮不调整已核对事实和编码分母，不新增采访或回访结果。

## 本轮变化

- 回访入口提供可编辑、可下载的UTF-8问题卡，包含读者输入、三个阶段的追问、匿名编号、日期、行为、失访与核对字段。无需联网或模型接口。下载不会上传输入，收起再展开保留本页草稿，刷新页面后清空。
- 静态构建默认不发起AI可用性请求，不显示不可用按钮；开发版或已明确开启的服务在检查可用后提供辅助回信。提示词和回访模板不是采访结果。
- 评论区使用“原创声音示意”，保留头像、身份、声音“非采集样本”的说明。头像素材、评论翻阅、视频和零默认浮动气泡继续沿用。
- 三条人物路径增加直达索引，跳转时避开顶栏；手机姓名与技艺标记分行排布，收紧局部留白，完整人物时间线留在主线。
- 统一版本号、维护说明、打开方式及打包内容。V1.1及更早的交付包、回档点保留。

## 验证范围

新增 tests/final-delivery.mjs 在320、390、768、1440像素下阻断外部网络，检查实际问题卡下载内容、中文编码、键盘操作、草稿保持、人物跳转、无横向溢出及无AI接口请求，并生成日间和夜读截图。

沿用事实联动、全台账复算、主线浏览器交互、生产降级阅读和背景影片测试。最终成品与源码ZIP需要重新解压、逐项校验SHA-256，实际启动解压后的预览服务，验证外网不可用时的390与1440像素阅读和下载。执行结果见交付目录“交付验收.json”。

浏览器检查使用本机Edge的手机尺寸与触摸模拟；本轮不声称实体手机或Safari认证。三维依赖仍有构建体积提示。尚未开展同批体验者回访和独立双人编码，94条采集指标的字段统计不替代10组报道片段的内容编码。
