# 回访助手：纯静态版本

本版不调用模型接口，无需密钥、服务器和模型余额。自由输入通过主题、意图与上下文匹配，组合成本作品范围内的资料说明和回访建议；不是通用大模型，也不代表实际采访。

内容位于 src/content/local-reply.ts，事实数字从 public-evidence.json 读取。回复支持同一句话包含多种关心事项，并在当前页面保留上一轮主题和最多五轮历史。输出逐字展开，支持停止、继续、清空；减少动态时立即展示完整文本。问题卡可以下载，输入与对话不上传、不持久化。

已覆盖鱼灯、徽墨、持续学习、教学支持、传播与证据、制作与入门、指标口径、实名人物、采访、日常、数字互动和参访等主题。规则有边界：开放领域与未收录信息会明确引导，不生成未知比例、实时门票或人物身份；复杂否定、隐喻和多层关系仍可能不能完全理解。

维护时优先新增不同问法的行为测试，再调整识别和段落。不要只为了增加关键词而让无关问题命中；尤其不能把“多少人继续学”回答成“接待了多少人”。

验证：npm run test:reply。浏览器测试需先启动生产预览 npm run preview，默认地址为 http://127.0.0.1:4173/ 。测试包括手机/桌面、停止与继续、短追问、资料链接、历史、下载、减少动态和零 API 请求。

GitHub Pages 只需发布构建后的 dist 内容，保留目录结构与相对路径；维护源码包的 docs 目录也包含同样的构建成品。无需 Vercel 或任何服务器函数。GitHub Pages 的大陆可达性仍应独立实测。
